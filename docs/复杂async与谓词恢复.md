# async 值传播与谓词恢复

聚合值仅在片段来自同一值、连续且顺序一致时重组。覆盖、混源或反序均保留为独立片段。

常量读取仅折叠 ELF 中可读、不可写且不与重定位重叠的区域，并保留精确位值。值类型接收者从调用前内存取得值拷贝，不推断未知调用后的回写。

全零结构体可表示为 default；非零构造要求布局匹配且字段为可写公开标量。数组、越界或 readonly 字段不满足此规则。

await 后的业务写入按字段身份和原执行位置表示。自动属性要求非虚且编译器生成的 setter。泛型方法签名匹配使用名称、泛型数量与参数类型。

谓词的无用选择值仅在无调用、内存访问和异常时消除。枚举常量保留类型与成员身份。async 归约失败时保留 SSA 的未决原因。
