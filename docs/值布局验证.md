# 值布局与返回数据流

## 规则

- 值类型字段偏移相对值数据起始；引用类型字段偏移包含对象头。
- 泛型值类型按实参计算字段位置，不修改泛型定义的偏移。
- 自然布局按字段对齐并补齐尾部；嵌套非泛型结构必须与元数据字段偏移和大小一致。
- 显式布局、自定义 packing/大小、未确定的值参数仍保留未知。
- 返回值保留寄存器分量及字节偏移；间接返回使用入口提供的缓冲区。

## 验证入口

在仓库目录执行，构建产物和日志放入已忽略的 `artifacts/`：

```powershell
dotnet build tests/Cpp2CS.Tests/Cpp2CS.Tests.csproj --no-restore -m:1 -p:UseSharedCompilation=false -o artifacts/checks
dotnet artifacts/checks/Cpp2CS.Tests.dll value-layouts
dotnet artifacts/checks/Cpp2CS.Tests.dll managed-returns
dotnet artifacts/checks/Cpp2CS.Tests.dll managed-calls
dotnet artifacts/checks/Cpp2CS.Tests.dll layout-model ../lib/arm64/libil2cpp.so ../lib/arm64/global-metadata.dat
dotnet artifacts/checks/Cpp2CS.Tests.dll prep ../lib/arm64/libil2cpp.so ../lib/arm64/global-metadata.dat Sekai.Mysekai,Sekai.Api
```

`prep` 覆盖命名空间及其子命名空间，保留方法实例，不按地址合并不同签名。该命令检查恢复准备阶段，不代表已经生成或验证完整 C# 方法体。

## 二进制证据

样本 SHA-256：

- `libil2cpp.so`：`6ce1de5c0357e122f153f62d648de1655b7f8a339b2ae1c575595868a361e4bb`
- `global-metadata.dat`：`a8ba1eca04a09e640a0fd71ac813b76f9470bc882e856f8382f9936311116bed`

当前 ARM64 样本的 `0x719f610` 是 `UniTask<bool>` 返回路径中的目标。在 `0x719f640` 写入偏移 `0xa` 的 short，在 `0x719f644` 写入偏移 `8` 的 bool，随后 `0x719f648` 用 `ldp x0, x1, [sp]` 读取返回分量。这与自然布局的 `source:0 / result:8 / token:10 / size:16` 一致。

真实模型字段检查得到 32,484 个已知字段、11 个未知字段、0 个越界；8,416 个类型可核对自然布局。`Vector3` 的大小为 12、字段偏移为 `0/4/8`；`Quaternion` 的大小为 16、字段偏移为 `0/4/8/12`。

目标 `Sekai.Mysekai`、`Sekai.Api` 及子命名空间共有 23,604 个方法定义，其中 357 个抽象方法；包含泛型实例的代码 case 为 23,390 个。返回布局和 SSA 检查失败均为 0，缺失边界为 0；仍残留 147,762 个调用破坏未知值，不能当作完整反编译成功。

这是静态二进制和元数据验证，不是游戏运行时验证。泛型实例布局仍按目标平台规则推导，不能由少量样本推称所有方法行为等价。
