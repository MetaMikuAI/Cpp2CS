# 循环清理区域恢复

`FinallyLoops` 根据 SSA 与 LSDA 检查清理协议。`FinallyLoop` 保存循环头、清理调用、继续位置、接收者栈槽、受保护调用和处理器节点。表达式前端和输出器使用该区域生成 try/finally。

协议要求：

- 可归约自然循环具有唯一普通出口，值类型接收者实现 IDisposable。
- 普通出口与处理器使用同一 Dispose 方法、接收者存储及 MethodInfo。
- 抛出路径由对应的 typed catch 和 cleanup 覆盖，不含额外业务处理区。
- 处理器不含额外存储、业务调用或循环；出口执行清理并保留原异常。
- 普通出口的清理前操作满足保护区边界约束。

间接返回保持聚合来源，接收者调用与字段读取共享局部存储。类初始化事实通过循环传播，循环内初始化不覆盖零轮路径。泛型字段类型由 MethodInfo 与元数据绑定。

`.flow.json`、`.ssa.json` 和 `.finally.json` 分别保存原生边、值来源和清理区域。输出描述托管语义，不覆盖全部 C++ 外来异常 ABI。
