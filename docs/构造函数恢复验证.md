# 构造函数恢复验证

## 恢复规则

- 沿可达控制流检查 `this` 的初始化状态。允许元数据准备、独立参数计算和本类字段写入先于基类构造；拒绝提前读取或泄漏 `this`、缺少初始化、重复初始化和回边重复调用。
- `protected` 访问按实际泛型基类核对，保留接收者类型限制，不能把泛型实参抹掉后比较继承关系。
- 构造委托从同类其他构造函数的二进制寻找候选。只有完整、无分支的后缀逐项一致，才改写为 `this(...)`；核对基类调用、参数、字段写入顺序及返回，不能按方法名或单个地址套规则。
- 新调用只接收此前已求好的值。拒绝提前字段读取、传入未初始化的 `this`、多余写入和未确定参数。保留结构体副本；参数副本被取地址时，不能把局部存储替换成原参数。
- 候选构造方法体随调用一并验证和输出，清单记录其地址和方法定义，不留下调用骨架的替代结果。当前候选不包含泛型类型中的构造函数、分支、异常区域、同步构造或多层构造委托。

浮点常量直接按位型输出，普通默认值不再经过多余的整数局部变量。NaN 使用整数位型重解释，避免 C# 的 `float.NaN` / `double.NaN` 表示丢失符号和载荷。

## 执行检查

输入为 ARM64 二进制与匹配元数据，哈希同[值布局验证](值布局验证.md)。

| 方法 | 地址 | 检查 |
| --- | --- | --- |
| `GetSuiteUserPartsApi..ctor(long)` | `0x51f7578` | 实际泛型基类的访问权限、基类调用次数、`long` 边界值写入 |
| `IdleLowerState..ctor`，三个参数 | `0x5631084` | 从实际方法体恢复构造委托；参数计算必须先于基类调用 |
| `IdleLowerState..ctor`，四个参数 | `0x56310e4` | 完整后缀证明与依赖输出，时长字段写入 |

`IdleLowerState` 的实际 CIL 和重新编译的 C# 都执行检查：对象参数身份、随机范围 `5f` / `8f`、时长的负零与 NaN 位型，以及参数计算抛异常时不进入基类。

随机函数和基类使用记录宿主，两个 `IdleLowerState` 构造方法体来自真实恢复。API 检查也只替换基类宿主，没有执行请求。以上均不等于 Unity 运行验证。

合成检查覆盖不同分支各初始化一次、未初始化返回、重复调用、`this` 副本与逃逸、基类观察字段初始化先后顺序，以及被 `ref` 写入的参数副本。常量检查同时执行原 CIL 和重新编译的 C#，覆盖单精度、双精度、极小值、无穷、负零和不同 NaN 位型。

## 全量结果

| 项目 | 数量 |
| --- | ---: |
| `Sekai.Mysekai`、`Sekai.Api` 全部代码 case | 23,390 |
| 可形成托管方法体 | 9,329 |
| 写出 CIL 的目标 case | 9,050 |
| 相比 `599ba63` 新增 / 回退的 CIL case | 272 / 0 |
| 新增 Mysekai / Api case | 171 / 101 |
| 尚未写出 CIL | 14,340 |
| 构造委托 / 已恢复依赖 | 1 / 1 |
| 回读通过的方法定义，含恢复依赖 | 9,187 |

前后地址集合和方法定义对应完全一致。构造委托依赖也在目标 case 中，没有额外增加目标定义计数。最终源码共 1,747 个文件，相对基线有 295 个变化：主程序集 287 个、Graphics.Data 8 个；其他三个程序集的 22 个目标文件未变。

主程序集的 1,701 个目标文件中仍有 7 项 C# 诊断，位于 `FixtureSelectorEventData`、`UIPartsFixtureThumbnail` 和 `MysekaiWeatherDialog`；另有 2 项既有范围外诊断。Graphics.Data 的全部 33 个文件、其中 24 个目标文件均为零错误。对应日志为 `compile-constructor-storage.log` 和 `compile-constructor-storage-graphics.log`。

## 当前边界

CIL 输出数量不代表完整业务可运行。仍有未恢复方法及骨架依赖；部分构造函数的字段初始化与未知构造重载混合存在，尚不能正确表达为 C#。不能通过提前基类调用或补写未知字段默认值消除这些诊断。

证据位于 `artifacts/recovered-constructor-storage/`。构建、构造执行和全量检查日志分别为 `constructor-storage-build.log`、`constructor-storage-check.log`、`constructor-storage-bodies.log`；浮点常量 CIL / C# 往返检查日志为 `constructor-nan-body.log`。构建为零错误，保留第三方 NSO 读取的三项既有警告。生成物不提交 Git。
