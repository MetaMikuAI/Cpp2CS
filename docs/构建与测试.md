# 构建与测试

在仓库根目录执行：

```powershell
dotnet build Cpp2CS.slnx -c Release
dotnet run --project tests/Cpp2CS.Tests -c Release --no-build
```

测试项目是可执行断言程序，失败返回非零退出码。独立字节数组作为存储切片的参考实现，不复用 IR 切片算法。

机器码对照使用输入二进制中的指令，外部调用由测试桩提供。编译夹具使用生成的方法体。测试结果描述各自输入和桩契约范围，不自动证明游戏运行时等价。

`tests/corpus` 保存测试输入，`artifacts` 保存运行产物。需要配置的测试显式接收文件路径，配置格式见根目录的 `native.example.json`。
