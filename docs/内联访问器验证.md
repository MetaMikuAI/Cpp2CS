# 内联访问器验证

原生代码可能把属性 getter/setter 内联为字段读写。直接照搬成 CIL 会越过私有字段的访问权限，因此根据元数据找到访问器，再用访问器自己的二进制验证是否等价。

## 恢复规则

- 从元数据的属性关联找候选，不根据字段名猜 getter/setter。
- 当前证明接受整理后只有一个基本块、一次直接字段读取或写入的访问器；返回值必须是该字段，写入值必须是原参数。
- 有额外读取、写入、计算、调用或异常区域时不通过。未封闭的虚方法、同步方法，以及含屏障或未证明可忽略的 hint 的方法，也不作为等价替换。
- 方法和字段共用访问权限检查；替换后的调用仍必须可访问。
- getter 保留在原读取位置，setter 保留原写入顺序。值类型内部写入不会改成“调用 getter，再修改返回副本”。
- 输出前同时检查调用者和访问器依赖，全部满足条件后才写入方法体。访问器依赖也有真实实现，不指向骨架占位体。

泛型访问器、引用返回、多块访问器和其他内联形式仍有未支持的情况。这里只证明局部字段访问等价，不证明整条业务调用链已恢复。

## 真实样本

输入二进制及元数据哈希同[值布局验证](值布局验证.md)。

| 地址 | 身份 | 二进制证据 |
| --- | --- | --- |
| `0xa45d0c8` | `MaterialRenderingSettingsItem.get_Attribute` | 从 `this+0x18` 读取 settings，判空，再从 `settings+0x10` 读 32 位字段 |
| `0xa45dab0` | `MaterialRenderingSettings.get_ShaderAttribute` | `ldr w0,[x0,#0x10]; ret` |
| `0xa45dab8` | `MaterialRenderingSettings.set_ShaderAttribute` | `str w1,[x0,#0x10]; ret` |

调用者恢复为访问 `settings.ShaderAttribute`，不再直接读取 `settings.shaderAttribute`。

测试从真实二进制生成上述方法体，在替代宿主中执行，并检查整数边界位型。测试宿主将枚举映射为底层整数，不加载 Unity 游戏运行时。另有合成的先读后写测试和计算属性、额外读写、值类型地址路径等反例。

## 全量结果

范围仍为 `Sekai.Mysekai` 和 `Sekai.Api`，含子命名空间，共 23,390 个代码 case。

| 项目 | 数量 |
| --- | ---: |
| 可形成托管方法体 | 8,285 |
| 写出 CIL 的目标 case | 7,975 |
| 相比 `14e6ce7` 新增 / 回退 | 687 / 0 |
| 未写出 CIL 的目标 case | 15,415 |
| 使用访问器恢复的 case / 替换位置 | 687 / 842 |
| 已写出的访问器依赖 | 360 |
| 目标集合之外额外写出的访问器 | 106 |
| 回读通过的方法定义（含依赖） | 8,081 |

新旧清单的 case 集合相同。五个程序集中的 1,747 个目标类型文件，Roslyn 编译诊断均为 0 错误；全程序集仍有先前记录的 6 项范围外错误。这不是全量行为验证，未恢复成员仍为骨架。

最终证据在 `artifacts/recovered-accessors-final/`，执行日志为 `artifacts/accessor-final-check.log`。加入屏障和 hint 拒绝条件后，与 `artifacts/recovered-accessors/` 的逐 case 输出状态、访问器证据完全相同，1,747 份目标源码逐字节相同；对应编译日志为 `artifacts/compile-accessors-*.log`。清单的 `accessors` 记录原访问位置、访问器代码地址、方法和字段身份。

## 复核命令

```powershell
dotnet build tests/Cpp2CS.Tests/Cpp2CS.Tests.csproj --no-restore -m:1 -p:UseSharedCompilation=false -o artifacts/accessor-tools -v:quiet
dotnet artifacts/accessor-tools/Cpp2CS.Tests.dll accessor-check ../lib/arm64/libil2cpp.so ../lib/arm64/global-metadata.dat
dotnet artifacts/accessor-tools/Cpp2CS.Tests.dll bodies ../lib/arm64/libil2cpp.so ../lib/arm64/global-metadata.dat artifacts/recovered-accessors Sekai.Mysekai,Sekai.Api
dotnet artifacts/accessor-tools/Cpp2CS.Tests.dll compile-saved artifacts/recovered-accessors/assemblies Sekai.Mysekai,Sekai.Api Assembly-CSharp
```

其余四个程序集的复核命令同 `compile-saved`，最后一个参数依次为 `Sekai.Mysekai.Graphics.Data`、`Sekai.Mysekai.HUD.Grid.Data.Color`、`Sekai.Mysekai.HUD.Grid.Data.ValueObject`、`Unity.RenderPipelines.Universal.Runtime`。
