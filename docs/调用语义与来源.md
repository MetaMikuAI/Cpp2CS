# 调用语义与来源

| 对象 | 来源 |
|---|---|
| 指令与范围 | Capstone 结构化操作数、ELF FDE |
| 全局地址 | ELF 重定位与元数据槽 |
| 字段布局 | Clang AArch64 布局 |
| 属性、枚举与泛型签名 | DummyDLL 元数据 |
| 调用参数 | 调用前状态与 ABI 分类 |
| 共享返回类型 | MethodInfo 与机器方法的对应关系 |
| 委托调用 | 同一对象的委托字段与 Invoke 签名 |

元数据初始化包含 helper 调用、屏障及异常行为。`Runtime.EnsureMetadataInitialized` 是这些操作的语义表示。空引用检查和字段读取保留执行次序。

恢复报告的 `nativeExecutionValidated=false` 表示恢复命令不执行机器码行为对照。恢复视图、编译检查、测试桩执行和游戏运行属于不同验证范围。
