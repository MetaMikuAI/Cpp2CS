# 条件值与整值返回验证

## 恢复规则

- 条件选择先核对一位条件及两侧位宽。同宽数值即使符号或浮点类型不同，也按原始位型选择；浮点不经过整数数值转换。引用与已证明的零合并为空引用，其他引用沿已有继承规则求公共类型。
- 非零整数不能冒充对象，未知来源和宽度不一致仍报告缺口。条件表达式不提前求值另一分支。
- 完整数值结构体可按字段布局打包成 8/16/32/64 位整数。要求无填充、无重叠、无未知字段，不解释引用或指针位型。
- 已知同类型、同位宽的结构体写入保持整个值，不拆为成员赋值。
- 单寄存器结构体返回若只是完整读取后的扩展、截断或位重解释，则在原读取位置保存结构体副本并返回。只接受同一块内有序且无其他用途的定义链；不移动读取，不借字段拆装绕过私有访问限制。

合成 CIL/C# 往返覆盖整数符号边界、负零、无穷、NaN 载荷、空引用、引用身份、结构体打包，以及读取后覆盖源值时仍返回旧副本。填充、重叠、引用、未知字段、部分读取和错误条件位宽均检查拒绝路径。

## 真实方法与参照

`GridAreaData.GetSquareMin` 位于 `0x58688ac`，输入为 `Vector3Int`，返回四字节的 `GridPosition`。原生代码在 `0x58688bc`、`0x58688cc` 使用 `csel` 合并 32 位值，经过整数运算后，在 `0x5868900` 调用 `GridPosition..ctor(int, int, int)`（`0xa45f880`），最后从栈上读回整个坐标。

`tests/oracle/grid_square_min.py` 读取原始 ELF 映射和指令，核对二进制哈希后用 Unicorn 执行 `0x58688ac` 至 `0x5868900` 的计算段。它在构造调用之前停止，记录三个完整 32 位实参，不代写运算公式。输入含 361 组边界组合及 1,000 组固定随机值。

执行测试恢复目标方法、真实坐标构造和所需的 `Vector3Int` 访问器。构造入口仅插入实参记录，后续保留完整恢复体。CIL 与重新编译的 C# 分别比较全部 1,361 组构造参数，并检查返回坐标的 bool、三个 sbyte 位型。

宿主保留字段类型和布局，类初始化接口映射到 CLR，宿主坐标类型没有原游戏的静态初始化依赖。该检查覆盖计算段、实际构造及返回，未证明游戏静态状态或 Unity 运行行为。

最终工具的 `phi-check`、`aggregate-check`、`buffer-check`、`field-store-check` 均通过，包含真实引用分支、StaminaData 加减、24 字节 Bounds 复制及材质构造链。对应日志为 `conditional-values-final-phi-regression.log`、`conditional-values-aggregate-regression.log`、`conditional-values-buffer-regression.log` 和 `conditional-values-field-store-regression.log`。
