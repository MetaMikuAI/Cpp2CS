# 条件边恢复验证

## 核心规则

原生编译器会在判空分支上复用对象寄存器：该边上对象已知为零，随后可将这个零并入整数或布尔结果。仅按变量的全局类型合并会拒绝这种情况。

`Ssa.EdgeConstants` 接入 `Propagate`，从条件边提取完整位型的相等事实，并将对应 φ 输入替换为新建的常量定义。

- 支持 64 位整数相等的真边、不等的假边、逻辑取反，以及合取真边和析取假边提供的事实。
- 常量定义放在前驱分支之前，无副作用；只替换对应正常边的 φ 来源，不替换变量的其他使用或异常输入。
- SSA 版本必须完全相同，比较必须覆盖完整存储宽度；32 位比较不证明 64 位高位。
- 浮点相等不作为位型相等，避免把负零换成正零。矛盾事实、重合分支和其他未支持条件保持原样。
- 新变量避开已有临时存储；不改动 CFG 边，后续仍校验定义唯一性、支配关系和 φ 前驱对应关系。

当前只使用直接条件边上的完整常量事实。跨多个基本块传递的条件、部分位宽约束和范围推断仍未实现。

## 真实样本

`Sekai.Mysekai.MysekaiGateModel.InitializeBasicProperties`，地址 `0x58a40a4`。输入哈希同[值布局验证](值布局验证.md)。

原生代码从 `this+0x10` 读取用户数据；根据其是否为空写入 `this+0x80`。非空时再读取 `user+0x28`，汇合后写入 `this+0x34`。判空边上的汇合输入原本仍是对象变量，现在替换为该边上已证明的零。

元数据确认这些字段分别为 `UserMysekaiGate`、`HasSetupOnce`、`isSettingAtHomeSite` 和 `IsSettingArea`。行为可概括为：

```csharp
var user = UserMysekaiGate;
HasSetupOnce = user != null;
IsSettingArea = user != null && user.isSettingAtHomeSite;
```

执行检查从真实二进制恢复完整方法体，替代宿主只提供字段。覆盖空数据、布尔真/假、覆盖旧字段、重复调用和空 this 的异常；未提供手写方法实现，未加载 Unity 游戏运行时。

## 验证结果

- 条件边改写前后差分：1,108 组输入通过，覆盖分支方向、常量、位宽、浮点正负零、SSA 版本、重合分支、循环退出和自环。另检查正常边事实不泄漏到异常输入。
- `body-check`、`phi-check`、`accessor-check` 原有执行测试继续通过。
- `Sekai.Mysekai`、`Sekai.Api` 及其子命名空间全部 23,390 个代码 case 的 SSA 检查通过，无缺失函数边界。

| 全量恢复项目 | 数量 |
| --- | ---: |
| 可形成托管方法体 | 8,319 |
| 写出 CIL 的目标 case | 7,999 |
| 相比 `d3b6edb` 新增 / 回退 | 18 / 0 |
| 尚未写出 CIL | 15,391 |
| 回读通过的方法定义（含访问器依赖） | 8,107 |

新旧 case 集合完全一致。新增输出包括门模型初始化、部分 NPC 交谈判断、家具数量查询等。除上述 `InitializeBasicProperties` 外，本轮没有逐一执行其他新增方法；`InitializeAllProperties` 的部分调用依赖仍为骨架，不能把它算作完整可运行链路。

1,747 个目标源码文件中有 9 个变化，均属于 `Assembly-CSharp`。该程序集重新运行 Roslyn 编译诊断，1,701 个目标文件为 0 错误；整个程序集仍有先前的 2 项范围外错误。其他四个程序集的 46 个目标源码文件逐字节未变，沿用此前诊断。编译诊断不等于行为验证。

证据位于 `artifacts/recovered-edges/`、`edge-gate-prep.log`、`edge-prep-all.log`、`edge-final-check.log`、`edge-body-check.log`、`edge-phi-check.log`、`edge-accessor-check.log` 和 `compile-edges-Assembly-CSharp.log`；日志均在 `artifacts/` 下。生成物不提交 Git。

```powershell
dotnet build tests/Cpp2CS.Tests/Cpp2CS.Tests.csproj --no-restore -m:1 -p:UseSharedCompilation=false -o artifacts/edge-tools -v:quiet

dotnet artifacts/edge-tools/Cpp2CS.Tests.dll prep ../lib/arm64/libil2cpp.so ../lib/arm64/global-metadata.dat Sekai.Mysekai,Sekai.Api
dotnet artifacts/edge-tools/Cpp2CS.Tests.dll bodies ../lib/arm64/libil2cpp.so ../lib/arm64/global-metadata.dat artifacts/recovered-edges-check Sekai.Mysekai,Sekai.Api
dotnet artifacts/edge-tools/Cpp2CS.Tests.dll compile-saved artifacts/recovered-edges-check/assemblies Sekai.Mysekai,Sekai.Api Assembly-CSharp
```
