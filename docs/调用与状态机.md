# 调用与状态机

字段地址、栈地址与读取值分开表示。栈视图按写入宽度保存，重叠写入更新对应范围；W 寄存器写入清零高位。

装箱读取完整值作为载荷。字段写入与 GC 屏障是有序的独立操作。运行时 helper 摘要受 ELF 哈希约束，类型检查的合并需要行为等价条件。

外部直接跳转在目标确定时表示为尾调用。不返回调用终止普通后继，异常后继单独处理。无环 Phi 在对应前驱赋值，不为缺少来源的值补默认值。

状态机及闭包上下文来自托管接口、属性和定义 token；同名重载通过 AddressAttribute 关联入口。地址用于机器适配，不取代托管方法身份。

LSDA 区域与异常动作供控制流层使用。读取 landing pad 不等于可以输出完整异常结构；格式参见 [LLVM Exception Handling](https://llvm.org/docs/ExceptionHandling.html)。
