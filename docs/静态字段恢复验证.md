# 静态字段恢复验证

## 恢复规则

- 从已确认的 `TypeInfo` 读取 `static_fields`，再按匹配元数据的字段偏移定位。当前布局限元数据版本 31、ARM64。
- 静态存储指针、常量偏移及来源相同的汇合只供恢复使用，不能作为 CLR 对象输出。不同类型或不同偏移的汇合保持未知。
- 普通字段必须完整匹配类型和宽度；结构体内部字段继续按实例布局定位。静态存储只包含声明类型自身的字段，不混入基类字段。
- 读取仍留在原定义位置。读、写、取地址分别输出 `ldsfld`、`stsfld`、`ldsflda`，同一字段的引用保持共享存储。
- 输入模型从 `ThreadStaticAttribute` 辨认线程静态字段；线程静态、常量、未知偏移和泛型静态布局不借用普通静态存储规则。
- 核对静态字段访问权限；`protected` 静态成员没有实例接收者，但仍受派生关系限制。只读静态字段仅允许本类静态构造函数写入或传递可写引用，不能绕过嵌套结构体字段检查。

类初始化沿用[类初始化恢复规则](类初始化恢复验证.md)，不因恢复静态字段而删去显式初始化。

## 执行检查

| 真实方法 | 地址 | 验证 |
| --- | --- | --- |
| `GCAllocChecker.get_Count` | `0x58a58d0` | 静态整数读取 |
| `GCAllocChecker.set_Count` | `0x58a5918` | 写入后通过真实 getter 回读，覆盖整数边界 |
| `NPCTalkReservationUtility.IssuePlanId` | `0x561bda4` | 读取、递增、写回并返回；连续调用与 `long` 溢出 |
| `Multi.MatchingController.get_Instance` | `0x5b75360` | 静态对象引用读取 |
| `Multi.MatchingController.set_Instance` | `0x5b753a8` | 对象身份与空值写入 |

五个方法均从真实二进制恢复，执行原 CIL，再将反编译 C# 重新编译并重复执行。宿主提供对应字段和类型，没有手写替代方法体，也没有加载 Unity；因此不证明匹配控制器的完整游戏行为。

合成检查覆盖读取后写入的顺序、两个 `ref` 参数共享静态字段、嵌套结构体原地修改、浮点负零与 NaN 位型、只读初始化及越权写入拒绝。反例还包括部分读取、错误类布局偏移、静态指针逃逸、不同偏移汇合和线程静态混用。

## 全量结果

输入哈希同[值布局验证](值布局验证.md)，测试范围仍为 `Sekai.Mysekai`、`Sekai.Api` 及全部子命名空间。

| 项目 | 数量 |
| --- | ---: |
| 全部代码 case | 23,390 |
| 可形成托管方法体 | 9,554 |
| 写出 CIL 的目标 case | 9,247 |
| 相比 `eee7d7e` 新增 / 回退 | 197 / 0 |
| 尚未写出 CIL | 14,143 |
| 回读通过的方法定义，含恢复依赖 | 9,385 |

前后 case 地址与方法定义对应一致。新增 case 均来自 `Sekai.Mysekai`；`Sekai.Api` 已全量检查，本轮没有新增。1,747 个源码文件中有 107 个变化：主程序集 106 个、Grid.Data.Color 1 个；其他三个程序集的 37 个目标文件未变。

主程序集 1,701 个目标文件仍有 156 项既有 C# 诊断，未增加，另有 2 项范围外错误。Grid.Data.Color 的全部 18 个文件、其中 9 个目标文件均为零错误。其余新增方法未逐一执行；依赖仍可能是骨架，CIL 数量不代表完整业务可运行。

证据目录为 `artifacts/recovered-static-fields-dev/`，集合与源码比较记录为 `static-fields-comparison.json`。构建、执行和全量日志为 `static-field-check-build.log`、`static-field-check.log`、`static-fields-dev-bodies.log`；公共路径回归为 `static-fields-class-init.log`、`static-fields-runtime.log`；源码诊断为 `compile-static-fields-dev.log`、`compile-static-fields-color.log`。生成物不提交 Git。

## 当前边界

尚未恢复泛型静态布局、线程静态访问、动态偏移及不同地址汇合。跨类型的私有静态字段暂未恢复成访问器调用；静态只读结构体的只读调用与防御性复制也需要额外证明。装箱与对象分配仍待接通。
