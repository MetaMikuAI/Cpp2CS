# 委托缓存恢复

缓存归约要求闭合的空值分支：读取静态槽、分配委托、调用对应构造方法、写回同一槽、匹配写屏障，并在合流处返回同一对象。额外副作用、逃逸临时值或不匹配字段阻止归约。

`DelegateCacheStatement` 显示为 `cache ??= Runtime.CreateDelegate<T>(target, method)`，保留目标读取、分配及构造顺序，仅在缓存为空时创建。该操作不引入锁或原子初始化。

非捕获 lambda 投影检查 CompilerGenerated 标记、所属方法、缓存字段、委托签名及唯一入口。方法体必须满足表达式归约条件。委托多次使用、返回委托或复杂方法体保留原形式；参数重命名按绑定进行。

类初始化守卫的重复消除要求所有前驱路径均具有对应初始化事实。源码投影与底层缓存语义分开，后者保留于 `.lowered.cs.txt` 和 `.view.semantics.json`，对应关系保留于 `.lambdas.json`。
