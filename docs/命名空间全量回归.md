# 命名空间全量回归

清单按 DummyDLL 的方法定义枚举，包含嵌套类型、编译器生成类型、重载与子命名空间。命名空间区分大小写；无 VA 的定义保留，原生符号中的额外实例单列。程序集和定义 Token 标识方法，VA 不代替方法身份。

```powershell
dotnet tests/Cpp2CS.Tests/bin/Release/net10.0/Cpp2CS.Tests.dll namespace-inventory <配置.json> <清单.json> <命名空间> [其他命名空间]
python tests/namespace_corpus.py <配置.json> <清单.json> <输出目录>
```

配置沿用 `NativeInputs`，`ManagedAssembly` 所在目录提供全部 DummyDLL；可填写 `Metadata` 记录其哈希。清单绑定二进制、metadata、符号、头文件及相关程序集的哈希。

运行器固定工具快照，按程序集复用恢复会话，每 256 个入口重建会话。每个结果立即写入 `results.jsonl`，源码保存在 `sources/`。崩溃保留标准错误和退出码，超时单独记录；恢复逻辑不捕获异常。相同输入和工具可续跑，变化后必须使用新输出目录。`--tool` 可指定单独构建的测试 DLL，`--timeout` 指定每个方法的秒数。

统计必须保留：待处理、无原生入口、缺少签名、共享签名未消歧、崩溃、超时、部分恢复和没有报告缺口。`--limit` 仅限制本次处理数量，不改变清单分母。额外原生符号在托管上下文未确认前单列待处理，不计作已恢复。

`no-reported-gaps` 仅表示当前诊断没有报告缺口，不等于语义正确、可以编译或运行等价。SSA、控制流、普通路径回退和 async 诊断均保留。覆盖数字必须与独立的指令执行对照、生成代码检查及副作用顺序检查分别报告。

发现问题后按指令、ABI、布局、数据流、调用和源码投影等共同原因修复；方法名和 VA 只允许出现在测试输入与证据中，不得作为生产恢复规则。
