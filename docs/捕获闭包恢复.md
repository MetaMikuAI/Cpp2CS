# 捕获闭包恢复

环境分配点标识捕获存储。字段、变量和委托构造分别保留身份；捕获变量在环境分配位置初始化，字段赋值在原位置投影为变量赋值。引用同一环境的委托共享变量及其更新。

投影检查 CompilerGenerated 标记、嵌套所属关系、原方法来源、委托签名和唯一机器入口。环境逃逸或出现未解释别名时，保留对象身份。

谓词归约保留短路次序。未绑定字段、额外副作用或不支持的控制流阻止投影。静态聚合分量必须来源相同、连续且顺序一致，属性替换需要独立 getter 的完整返回体依据。

`.lowered.cs.txt` 保存分配、初始化、缓存和写屏障，`.closures.json` 保存捕获绑定及回调指令。嵌套环境与循环作用域见 [嵌套与循环闭包](嵌套与循环闭包.md)。
