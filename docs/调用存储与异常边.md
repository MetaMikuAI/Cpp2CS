# 调用存储与异常边

间接返回按 ABI 绑定返回缓冲。正常返回后的字节来自同一调用结果；异常出口不保证完整写入。未知缓冲地址使可能别名的旧值失效，部分写入按字节覆盖。

可变值类型接收者使用调用后的存储身份，字段读取保留该身份。`ssa-managed.json` 的 `callStorages` 区分间接返回和可变接收者效果；这些效果描述正常返回的存储约定，不代表被调用方法的内部实现。

LSDA 动作链包含 cleanup 或 catch-all 时，异常路径经过对应处理器；仅包含 typed catch 时，保留类型不匹配的展开出口。重抛入口保留原异常及其托管 trace，运行时摘要受二进制哈希约束。

无基类的元数据句柄解析为 null。
