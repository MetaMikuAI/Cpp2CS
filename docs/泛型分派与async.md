# 泛型分派与 async

泛型调用沿 `MethodInfo → 实例类型 → RGCTX 槽 → 绑定后的接口 → 方法签名与 ABI` 解析。泛型定义按名称和泛型元数区分；上下文槽必须具有声明及实际类型参数依据。

虚调用要求 vtable 来自同一接收者的 klass，方法槽与 MethodInfo 配对，签名唯一。隐藏 MethodInfo 的位置由 AAPCS64 分类决定。抽象方法无 RVA 时，签名补充要求唯一的无参托管声明。

每个 await 具有独立调度身份。协议检查包括状态入口、source/token 来源、保存、恢复、清空、Pending 分支、空 source 后继、调度后返回及异常出口。协议收缩保留外部业务调用、分支、堆写入和返回。

嵌套字段保留完整访问路径。自动属性识别需要编译器生成的 getter；bool 低位掩码消除要求原参数为 bool。数值条件操作保留机器位宽。

async 业务图归约要求符合其支持的控制流结构。未满足协议的循环、Phi、builder 或泛型上下文产生未恢复项。
