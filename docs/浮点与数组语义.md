# 浮点与数组语义

`OperationExpression` 表示类型化数值操作、条件选择、数组分配和元素位置。类型、操作及输入共同参与验证、Phi 展开、替换、命名和序列化。

标量 `scvtf`、`fdiv`、`frintp`、`fmov`、`fcvtps`、`fcmp` 和条件选择保留精度、位宽及舍入语义。不支持的指令变体产生诊断。AAPCS64 调用保留 V8–V15 的低 64 位。

数组类型来自元数据，数组头、元素类型和步长来自布局。分配、长度、元素存储、动态类型检查和写屏障分别表示。条件选择保留输入读取的求值时点，整数加法保留回绕语义。

FCVTPS 表示向正无穷取整、越界饱和和 NaN 为零。托管视图不模拟 FPCR 陷阱、FPSR 状态位或 NaN 载荷传播。指令定义参见 [Arm FCVTPS](https://documentation-service.arm.com/static/5f3fa899428f7a6b3328fd44)。
