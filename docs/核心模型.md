# 核心模型

## 身份与类型

| 对象 | 身份与职责 |
|---|---|
| `DefinitionId` | 构建、image 和 token 标识的定义 |
| `TypeRef` | 类型定义、泛型实参、指针、ByRef、数组或泛型参数 |
| `GenericParameterId` | 所属定义、类型或方法类别、参数位置 |
| `MethodInstance` | 方法定义、类泛型实参和方法泛型实参 |
| `NativeAddress` | 构建与 RVA，可关联多个方法实例 |
| `TypeLayout` | 布局类别、大小、对齐、字段范围和 payload 起点 |
| `MetadataSlot` | 保存元数据引用的存储槽 |
| `Bits` | 定宽位值 |
| `StorageAddress` | 存储区域与字节偏移 |
| `CallSite` | 调用前寄存器、内存、目标和候选方法 |
| `NativeSignature` | 用于机器 ABI 分类的签名 |

泛型替换递归处理类型、指针、数组及 ByRef；未绑定参数保持原状，循环替换报错。泛型实参与操作数序列按内容比较。

字段偏移相对所选布局的起点。装箱布局包含对象头，`PayloadOffset` 标识值起点；显式重叠字段可以共享字节范围。

托管方法实例与机器签名独立。同一机器地址的多个实例保留为候选，不能仅根据地址合并身份。`Evidence` 保存来源信息，不自动判定来源的真实性。

## 存储与调用

字节值按小端拼接。存储状态不可变，部分写入更新对应字节，连续切片可以重组原值。合流中的相同字节值保留，不同值使用 Phi 表示。未知别名范围使受影响的存储信息失效。

状态、块、调用和输入值的 ID 在函数上下文中唯一。机器 SSA 按定义身份引用值，Phi 按前驱及边记录输入。循环回边可以引用构造中的 Phi。

AAPCS64 分类处理整数、float/double、小聚合、HFA、栈参数、大聚合地址参数和 X8 返回缓冲。未知布局导致分类失败。可变参数、HVA/SVE/SME、半精度与四精度浮点不在分类范围内。

调用使易失寄存器失效，V8–V15 保留低 64 位，X18 按未知平台策略失效。W 寄存器写入将对应 X 寄存器的高位清零。返回缓冲缺少指针来源时保留未知存储位置。

`CallEffects` 分别描述内存写入、异常和不返回行为。普通返回与异常出口使用独立状态；未知调用保留输入与候选，不生成缺失参数的默认值。

ABI 定义参见 [Arm AAPCS64](https://github.com/ARM-software/abi-aa/blob/main/aapcs64/aapcs64.rst)。

## 原生分析与托管语义

导入器从 ELF 和 metadata 生成符号、C 布局声明和托管程序集。原生适配层使用 Dumper 名称、DummyDLL 签名及 Clang 的 AArch64 布局结果关联类型与字段；这一名称适配层与 `Model` 中的定义身份模型分开。

ELF FDE 提供函数边界，LSDA 提供异常区域。控制流包含普通返回、异常分派、清理、展开和尾调用边。循环分析保留回边；无法归约的区域产生未恢复项。

托管语义层以 SSA 为值来源，结合签名、布局、MethodInfo 和运行时摘要解释调用与存储。接口分派需要接口槽与查找路径匹配；共享泛型调用需要相应上下文。运行时 helper 摘要仅在二进制哈希匹配时启用。

async 归约检查挂起状态、awaiter 存储、结果获取及完成路径。闭包投影以环境分配点标识捕获存储，父环境链接保留共享关系。缺少协议条件时保留未恢复信息。

## 源码视图

原始语义与源码投影分开保存，视图变换不修改原始 IR。字段读取保留求值时点，空引用检查的合并要求相邻解引用。委托缓存归约要求存储槽、构造结果与合流值一致。

元数据初始化保留调用次序、屏障和异常语义。未知副作用、未绑定泛型和未解析控制流显式保留。输入哈希用于区分来源，不证明二进制与 metadata 彼此匹配；C# 视图也不构成运行时等价证明。
