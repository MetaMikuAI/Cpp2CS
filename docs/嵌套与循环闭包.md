# 嵌套与循环闭包

环境分配位置决定变量作用域：循环外的环境对应共享变量，循环内的环境对应每轮独立变量。捕获读取不能替换为初始赋值。

父环境链接由字段类型和分配对象建立。链接要求单次赋值，且初始化支配读取及委托构造。多个回调沿父链接访问同一存储。

读取与修改保留执行位置。字段快照不能移入延迟执行的 lambda；块 lambda 保留空检查、读取、调用和返回。

自然循环按支配关系识别。活跃寄存器及合流值具有类型，入口和回边按边执行并行赋值。虚调用要求接收者、klass、vtable 槽、MethodInfo 和托管签名对应。

环境逃逸、父链接重赋值、未知字段、不可归约循环和不支持的异常区域均保留诊断。源码投影不保证反射名称、对象分配数量或原生异常 ABI 相同。
