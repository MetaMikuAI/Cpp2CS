# SysV 分类证据

依据 [AMD64 psABI §3.2.3](https://gitlab.com/x86-psABIs/x86-64-ABI)；AAPCS64 规则表依据 [AAPCS64 2025Q1 §6.8.2、§6.9](https://github.com/ARM-software/abi-aa/blob/2025Q1/aapcs64/aapcs64.rst)。

`generate.py` 用固定种子生成 C 类型、签名及汇编探针，用 gcc 编译调用方和返回值提供方。生成器不读取或执行分类器。先按本机约定取得重任务锁，再执行 `python3 tests/Cpp2CS.Tests/AbiEvidence/generate.py`。检查只读 `sysv.json`，不需要 gcc。

每个类型的大小、对齐和字段偏移均经 C 静态断言核对。每个签名执行四轮，每个字段字节四轮的取值组成唯一标记；浮点只搬运，不参与算术。调用经可变函数指针进入汇编探针；被调返回函数是独立的 gcc 函数，禁止内联。空聚合使用 GNU C 零大小扩展；单字节 C++ 空对象另由规则表覆盖。

`types` 描述类型；`parameters`、`result` 是类型下标。`arguments`、`returns` 的每项为 `[值内字节偏移, 观测位置列表]`。编译器可能在未使用的槽留下临时副本，所以保留全部匹配位置。检查要求分类器指定位置匹配，并再次核对四轮原始字节；它不声称其他匹配位置都是 ABI 保证的位置。字段字节必须完整覆盖；填充没有值语义，不作相等断言。

`snapshots` 是四轮连续快照的 Base64。每轮 2529 字节：

| 相对偏移 | 内容 |
|---|---|
| 0–47 | 六个整数实参槽，每槽 8 字节 |
| 48–175 | 八个浮点实参槽，每槽 16 字节 |
| 176–2223 | 栈实参区前 2048 字节，起点不包含返回地址 |
| 2224–2239 | 两个整数结果槽 |
| 2240–2271 | 两个浮点结果槽 |
| 2272–2527 | 间接结果缓冲区 |
| 2528 | 整数结果零槽是否等于所传缓冲区地址 |

`arguments` 位置相对本轮起点；`returns` 位置相对 2224。标记为 `uint32((token + 1) * 2654435761)` 的四个字节；参数 token 为 `参数序号 * 1024 + 值内偏移`，返回 token 为 `32768 + 值内偏移`。`echo` 表示四轮都回传相同缓冲区地址。主调用帧留有清零区域，避免采样越过调用栈进入启动参数。

`coverage` 和 `returnCoverage` 统计实参和返回的形状次数，形状可能含内部填充。重复边界试验保留；检查另要求去重后至少 300 个签名。原始快照含未规定的位和地址，因此重新生成的数据不保证逐文件相同，字段位置断言应保持一致。
